# Contributions

## How to read this file

Git history shows the account that pushed a commit. It does not show who
reviewed, tested, designed or presented. This file records the rest, and it
records only work that has actually happened.

**We do not manufacture history.** If one person makes all the commits, the
contributor graph will show one person, and we will say so plainly rather than
create commits to disguise it.
